Matriz de descansos

Aplicación web para gestionar y asignar descansos al personal. Calcula las fechas correspondientes según los días en ruta de cada empleado y utiliza un semáforo visual para identificar prioridades. Incluye filtros por nombre, historial de solicitudes y registro de evidencias en PDF.

Impacto del proyecto

Homologación y validación de datos

Proyecto enfocado en la gestión, ejecución y seguimiento del proceso de homologación de datos. Realicé la estandarización y corrección de información directamente en la base de datos, aplicando reglas de negocio para validar la consistencia de los registros.

También brindé capacitación a nuevos integrantes sobre los criterios de homologación y desarrollé una herramienta en Python para apoyar la validación y revisión de grandes volúmenes de datos.

Impacto del proyecto

  • Contribuyó a la estandarización y consistencia de la información mediante la ejecución de correcciones directamente en la base de datos.
  • Facilitó la revisión de grandes volúmenes de registros mediante una herramienta de validación desarrollada en Python.
  • Favoreció la continuidad del proceso mediante el seguimiento de avances y la capacitación de nuevos integrantes.

Tecnologías:
Python · SQL Server · SQL
